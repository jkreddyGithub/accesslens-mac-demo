AccessLens entitlement review demo for Mac

Requires Java 17 or newer.

1. Extract this ZIP.
2. Open Terminal. Type cd followed by a space, drag the extracted AccessLens-Mac-Demo folder into Terminal, then press Return.
3. Run:
   java -version
   java -jar access-review-demo.jar
4. Keep Terminal open and visit http://localhost:8080
5. Username: admin
   Password: AdminDemo!2026

Stop with Control+C. This demo uses synthetic data only and records review decisions without changing real access. Data is saved in the data subfolder. It requires no Node.js, Maven, Docker or AI account.

If Java is not installed, install a Java 17+ JDK for your Mac's processor, then reopen Terminal.
If port 8080 is busy, run java -jar access-review-demo.jar --server.port=8082 and visit http://localhost:8082

Full source and interview documentation are in the separate source ZIP.
